================================================================================
                       PROJECT ABSTRACT — VARTALAAP (वार्ताلاપ)
         Intelligent Real-Time Collaborative Messaging & Team Workflow Platform
================================================================================

TITLE OF THE PROJECT:
Vartalaap: Next-Generation Real-Time Collaborative Communication & Workflow Platform

TECH STACK:
Java 21, Spring Boot 2.7.18, STOMP WebSockets, Spring Data JPA, MySQL 8.0, 
HTML5, CSS3, JavaScript (ES6+), Spring Mail (SMTP), Ollama AI Integration.

--------------------------------------------------------------------------------
1. INTRODUCTION & PROBLEM STATEMENT
--------------------------------------------------------------------------------
In modern software engineering and enterprise environments, team communication is 
heavily reliant on instant messaging platforms. However, traditional consumer 
messaging applications (e.g., WhatsApp, Telegram) treat conversation streams 
purely as unstructured text. Consequently, technical consensus, architectural 
decisions, task assignments, and time-critical deadlines frequently get buried 
within multi-hundred-message chat threads. Switching contexts between chat tools 
and external project management software (such as Jira or Trello) creates 
cognitive friction, information fragmentation, and decreased productivity.

--------------------------------------------------------------------------------
2. PROPOSED SOLUTION & SYSTEM OVERVIEW
--------------------------------------------------------------------------------
Vartalaap (वार्तालाप) is an intelligent, full-duplex real-time communication 
platform designed to unify messaging with automated project workflow synthesis. 
Built on a high-performance Java Spring Boot backend and an ultra-responsive 
HTML5/CSS3/JS single-page frontend, Vartalaap leverages STOMP WebSockets to deliver 
sub-5ms messaging latency while converting raw conversation streams into structured 
and actionable team artifacts.

--------------------------------------------------------------------------------
3. KEY SYSTEM MODULES & INNOVATIONS
--------------------------------------------------------------------------------
I. REAL-TIME EMAIL OTP VERIFICATION:
   - Enforces 2-step registration security via Gmail SMTP integration.
   - Requires users to verify a 6-digit OTP sent to their Gmail before password 
     creation fields are unlocked. Enforces 6-32 character password complexity.

II. LIVE 3-DOTS MESSAGE CONTROL MENU (EDIT & DELETE):
   - Integrates an interactive 3-dots menu (⋮) on message bubbles.
   - Enables real-time message editing (PUT /messages/{id}) and deletion 
     (DELETE /messages/{id}) with instant STOMP WebSocket synchronization 
     across all connected client screens.

III. CONVERSATIONAL DECISION MEMORY INDEX (🧠 Decision Memory):
   - Automatically parses and indexes key technical and architectural decisions 
     made during discussions.
   - Provides natural-language AI query recall (e.g., "What database port did we 
     decide to use?") returning exact historical consensus without manual scrolling.

IV. AUTOMATED IN-CHAT TASK TRACKER (📋 Task Tracker):
   - Extracts actionable tasks, assigned team members, and deadlines directly from 
     chat conversations.
   - Maintains an interactive checklist drawer synchronized with the backend.

V. CONTEXT-AWARE SCHEDULED REMINDERS (🔔 Scheduled Reminders):
   - Parses temporal triggers and deliverables from chat context, scheduling 
     time-triggered notifications for assigned users.

VI. IN-STREAM DOCUMENT INTELLIGENCE & Q&A (📄 Document Q&A):
   - Supports uploading PDF, text, and code documents directly within chat threads.
   - Provides instant AI summarization and inline contextual Q&A capabilities.

--------------------------------------------------------------------------------
4. WEBSOCKET ARCHITECTURE SUMMARY
--------------------------------------------------------------------------------
Vartalaap establishes a persistent, full-duplex TCP WebSocket connection using 
the STOMP protocol. Compared to traditional HTTP polling (which incurs 500-1000 
bytes of header overhead per request), WebSockets reduce data frame overhead to 
2-10 bytes per packet. This enables instant bi-directional server push for live 
chat messages, online presence tracking, system notifications, and immediate 
message edit/delete frame broadcasts.

--------------------------------------------------------------------------------
5. FUTURE ENHANCEMENTS & ROADMAP
--------------------------------------------------------------------------------
1. AI Conflict & Architectural Misalignment Detector: Proactive Sentiment and 
   logic monitoring to detect conflicting decisions across parallel channels.
2. Zero-Knowledge Client-Side Secret Redaction: Automatic client-side masking 
   of API keys, database credentials, and PII before socket transmission.
3. Live Speech-to-Speech Subtitle & Tone Normalizer: Real-time voice transcription 
   with automated professional tone transformation.
4. Predictive Thread Summarizer & Decision Tree Visualizer: Offline catch-up AI 
   synthesizing long unread threads into role-customized decision trees.

--------------------------------------------------------------------------------
6. CONCLUSION
--------------------------------------------------------------------------------
Vartalaap demonstrates a powerful paradigm shift in collaborative software by 
embedding intelligent project management directly into real-time conversation 
streams. It eliminates context-switching, preserves critical decision history, 
and accelerates team execution.

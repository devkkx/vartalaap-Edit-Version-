# ⚡ Vartalaap Backend (Spring Boot 2.7.18 + Java 21)

This directory contains the Spring Boot backend service for **Vartalaap**, providing STOMP WebSockets, REST APIs, JPA Persistence, and Gmail SMTP OTP Verification.

For full project documentation, architecture diagrams, and future roadmap, refer to the root [README.md](../README.md).

---

## 🛠️ Quick Commands

```bash
# Build project
mvn clean package -DskipTests

# Run JAR
java -jar target/prochat-1.0.jar
```

Server runs on `http://localhost:8081`.
